# institut-maranatha-goma
A fully responsive, multi-page school website built with HTML5, CSS3, and JavaScript for Institut Maranatha in Goma, DRC. Features interactive program filtering, admission pre-registration form validation, and dedicated sections for Adventist education.
# 🏫 Institut Maranatha — Goma School Website

A modern, responsive, multi-page web application built as a final school project / final exam. This website represents **Institut Maranatha**, a Seventh-day Adventist educational institution located in Mabanga, Karisimbi Commune, Goma, North Kivu, Democratic Republic of the Congo.

---

## 📂 Project Structure

The project is organized into modular files linked together with a shared stylesheet and JavaScript file:

```text
institut-maranatha-website/
├── index.html          # Home page with stats, pillars, and news
├── about.html          # Principal's message, mission/values, and facilities
├── academics.html      # DRC educational levels with interactive category filtering
├── student-life.html   # Pathfinder clubs, choir, and sports activities
├── admissions.html     # Enrollment documents and working pre-registration form
├── contact.html        # Goma campus location, hours, and inquiry form
├── style.css           # Global design system, colors, layout, and responsive rules
├── script.js           # Mobile navigation toggle, dynamic filters, and form validation
└── images/             # Directory for campus and student photography

✨ Key Features
Multi-Page Architecture: Clean navigation across 6 distinct pages (Home, About, Academics, Student Life, Admissions, Contact).

Interactive Academic Filtering: Built with vanilla JavaScript to let users filter classes and DRC humanities options instantly.

Form Validation & Reference Generator: The admissions and contact forms feature real-time client-side validation and generate a unique reference number (e.g., MAR-482910) upon successful pre-registration.

Fully Responsive Design: Optimized for mobile phones, tablets, and desktop displays using CSS Flexbox and Grid.

Custom Visual Design: Styled using a professional academic color palette (Deep Navy, Gold, and Clean Slate).

🛠️ Technologies Used
HTML5 (Semantic markup)

CSS3 (Custom properties, CSS Grid, Flexbox, Media Queries)

JavaScript (ES6+) (DOM manipulation, event handling, form verification)
